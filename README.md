# shogi

将棋エンジンを実装するまでの基盤部分です。
とはいえ基本的にエンジンが欲しいかわからない為、現状は盤面を教えてくれるだけ。

王手負けをしてしまうが、ルール上の動作をできるようにはなったので一旦公開

## エンジンのサンプル

- _samples/giveup.go すぐ投了するエンジン
- _samples/move.go 可能な手をランダムで動作するエンジン
- _samples/check.go 王手を回避するエンジン
- _samples/thinking.go 3階層の予測を行うエンジン

# 必須な機能

- オプション設定(この機能としてログ設定を提供)
- オプション設定(エンジンが設定できるようにする)
- 候補手をGUIに出す
